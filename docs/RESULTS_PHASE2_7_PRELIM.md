# Phase 2.7 Preliminary Interaction Diagnosis

Status: **EXPLORATORY / POST-HOC.**

This note records descriptive patterns from the failed Phase 2.6 confirmatory
raw result. It does not validate a replacement law.

## Renderer-local feature summaries

Across 640 non-identity permutation effects, simple movement features did not
produce a clean universal explanation.

Notable descriptive summaries:

- moving the query-antecedent-bearing premise center by +1 position had mean
  effect about -0.04275;
- moving it by +2 positions had mean effect about -0.04547;
- conjunction-premise movement had near-zero global linear correlation with
  effect, despite some extreme movement buckets being negative;
- moving a direct query-edge premise showed a stronger correlation, but that
  feature occurs only in the single direct-anchor family and therefore cannot
  support cross-family generalization.

This means a one-feature explanation such as "conjunction earlier causes the
effect" is not supported by the current exploratory summary.

## Pairwise premise-order decomposition

For each family, the six S3 effects were fit descriptively with:

`effect(pi) ~= a + theta_12 z12(pi) + theta_13 z13(pi) + theta_23 z23(pi)`

where `zij` records which original premise appears first.

Family-level R2 values on the Phase 2.6 data:

```text
branch_to_conjunction_positive   0.8424
conjunction_gate_negative        0.7587
conjunction_source_positive      0.6929
direct_anchor_positive           0.1939
downstream_cycle_negative        0.6534
fork_join_positive               0.6716
fork_missing_join_negative       0.5484
reverse_join_negative            0.4726
```

Mean family R2: about 0.6042.

This suggests that, within many families, much of the six-point permutation
response surface can be compressed by pairwise precedence terms. However the
coefficients are family-specific, and the direct-anchor family is a clear weak
fit.

## Current hypothesis status

The next plausible hypothesis is no longer a global permutation identity law.
A better candidate is:

> premise-order effects are largely generated by pairwise precedence
> interactions whose coefficients depend on formal/syntactic premise roles.

That hypothesis is still too broad for a new confirmatory experiment. Phase 2.7
should next map pairwise coefficients to a small number of mechanically derived
premise-role features and test whether those coefficients generalize under
leave-one-family-out analysis.

No S3 representation, equivariance, compositionality, or categorical claim is
supported by this decomposition.
